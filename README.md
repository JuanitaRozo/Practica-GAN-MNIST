# Red Generativa Antagónica (GAN) – MNIST

## Descripción
Esta actividad implementa una Red Generativa Antagónica (GAN) utilizando Python, TensorFlow y Keras, con el propósito de generar imágenes artificiales de números escritos a mano mediante el conjunto de datos MNIST.

## Objetivo
Comprender el funcionamiento del aprendizaje adversarial mediante la construcción y entrenamiento de un generador y un discriminador.

## Herramientas utilizadas
- Python
- Google Colab
- TensorFlow y Keras
- NumPy
- Matplotlib
- Dataset MNIST

## Desarrollo
Se construyó una GAN compuesta por:
- **Generador:** crea imágenes artificiales a partir de ruido aleatorio
- **Discriminador:** identifica si las imágenes son reales o generadas

El modelo se entrenó durante 50 épocas y permitió generar imágenes similares a los dígitos manuscritos

## Resultados
Se obtuvieron imágenes artificiales, gráficas de pérdidas y los modelos entrenados, evidenciando el aprendizaje de la red neuronal.
